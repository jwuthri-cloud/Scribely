# Scribely

**Your invisible AI meeting assistant.** Live transcription, AI-powered Q&A, and real-time insights — all running locally on your Mac. Completely invisible to screen sharing.

- macOS 13 (Ventura) or later
- Apple Silicon (M1+) recommended
- 2 GB free disk space

---

## Quick Start

1. **Download & Install** — Download the DMG, drag Scribely to Applications, and launch.
2. **Grant Permissions** — Allow microphone and screen recording when prompted.
3. **Install Extension** *(optional)* — Add the Chrome extension for best audio in browser meetings.
4. **Start a Meeting** — Press `Alt+M` or click Start Meeting. Scribely transcribes automatically.

---

## Features

- **Live transcription** — Local Whisper models, no cloud required
- **AI Q&A** — Ask questions about your meeting in real time
- **Real-time insights** — Action items, decisions, and key mentions detected automatically
- **Screen-share invisible** — Overlay never appears in recordings
- **Privacy-first** — Audio stays on your machine
